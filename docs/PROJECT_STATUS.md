# 项目状态

本文档描述当前代码实际具备的能力，不代表未来计划已经完成。

## 已完成

### 基础工程

- 单模块 Android 工程，applicationId 与 namespace 为 `com.zhy20.teleprompter`。
- Kotlin、Compose、Material 3、Navigation Compose 和 Kotlin DSL 已配置。
- minSdk 26、targetSdk 36、compileSdk 36.1。

### Design System 与页面

- 深色主题、冷灰表面、橙色主操作和统一 Token。
- 首页/台本库、编辑页、样式启动页、提词播放页、控制端页和设置页。
- 手机与平板响应式布局，平板横屏支持左侧导航和双栏内容。
- 中文默认界面和英文资源预留。

### 台本库

- 全部台本、未分类和单层台本夹筛选。
- 新建、重命名、移动和删除台本。
- 新建、重命名和删除台本夹；删除台本夹会将台本移动到未分类。
- 资源列表独立滚动，管理和控制端区域保持可见。

### 文件导入

- TXT 文件导入：台本库主操作区点击“导入文件”打开系统文件选择器。
- 支持 UTF-8（含 BOM）、UTF-16 LE/BE（含 BOM）和 GB18030 中文编码识别，兼容 Windows/Unix/旧 Mac 换行。
- 文件大小上限 5 MiB，读取前通过 `OpenableColumns.SIZE` 检查并流式读取二次限制。
- 导入内容转换为 `ScriptDocument`，由 Repository 原子创建完整台本（派生纯文本、字数、预计时长并复制全局默认播放设置）。
- 导入后自动进入该台本编辑页；错误以 Snackbar 提示，不创建半成品台本。
- 只读取用户主动选择的文件，不申请存储权限，不复制原文件，不长期持有文件 URI。
- 导入遵循当前台本夹筛选：具体台本夹导入到该夹，全部/未分类导入到未分类。
- DOC/DOCX 导入：同一“导入文件”入口，系统文件选择器可选 `.txt`、`.doc`、`.docx`，格式由文件内容自动识别（不新增格式选择对话框）。
- DOCX（OOXML）直接解析：正文段落、粗体/斜体/下划线、表格（行内制表符分隔单元格）、超链接显示文字、列表文字、Run 内换行和制表符；忽略图片、页眉页脚、批注、脚注尾注、文本框、公式和页面布局。
- DOC（二进制 OLE2）解析：稳定提取正文、自然段、表格文字；基础样式仅在解析器可靠提供时保留，无法恢复时降级为纯文本（正文可用 > 格式完整）。
- Word 导入安全限制：源文件 ≤ 20 MiB，DOCX 解压总量 ≤ 64 MiB、ZIP 条目 ≤ 4096、单条目 ≤ 16 MiB，段落/表格/字符数上限，XML 禁用外部实体和 DTD；加密文档、损坏 ZIP/OLE、超大或结构过复杂的文档均返回明确错误且不创建台本。

### 富文本编辑

- 选区级粗体、斜体、下划线和组合样式。
- 撤回、700 ms 防抖自动保存、保存状态和失败重试。
- 标题与正文统一 revision，避免旧保存回执覆盖新草稿。

### 数据持久化

- Room 保存台本、台本夹、富文本 JSON、派生纯文本和播放设置。
- Preferences DataStore 保存全局默认播放设置和语言。
- Repository 负责序列化、默认值、派生字段和数据异常转换。
- Room schema 进入 `app/schemas/` 版本控制。

### 播放设置与提词播放

- 显示预设、字号、文字对齐、方向、镜像、速度/目标时间模式。
- 倒计时、横线/提词条、滚动播放、暂停、恢复、进度微调和长按退出。
- 播放预览和正式播放共用视口和排版规则。
- 播放与暂停控制栏使用固定槽位；倒计时期间使用全屏数字覆盖。

### 测试与发布基础

- JVM 单元测试覆盖模型、序列化、编辑器、播放引擎和触控策略。
- AndroidTest 覆盖 Room、Compose 视口、提词辅助和触控。
- 已配置开源仓库文档、Apache-2.0 许可证和基础安全忽略规则。

## 部分完成

- 控制端页面和连接状态是本地 Mock，尚未使用网络传输。
- 轻量富文本编辑器没有重做、格式继承和完整 IME 组合样式。
- 播放引擎已使用真实布局和时间轴，但仍是应用内会话，未提供独立播放服务。
- Android 设备兼容性、TalkBack、大字体和长时间播放压力测试还需要更多矩阵验证。

## 尚未开始

- Markdown 导入（架构已预留 importer 扩展点，尚未实现）。
- 局域网发现、二维码配对、WebSocket/TCP/UDP 通信和远控同步。
- 一对多设备、云同步、账号、回收站和多级文件夹。
- 语音识别、语音跟随和逐词阅读位置。
- 正式测试版发布、截图回归和持续集成工作流。

## 已知限制

- 中文语速是启发式估算，不替代真实语音识别或逐词计时。
- 当前数据库版本为 1，未来字段语义变化需要显式 Room Migration。
- 播放状态恢复依赖当前应用会话，尚未设计跨设备或跨进程 Session 持久化。
- 目前没有正式产品截图，因此公开 README 不引用截图资源。
- DOC 导入保留的格式有限：仅尽力保留粗体/斜体/下划线和表格文字，字符级样式（颜色、字号、字体）不保留；Word 文档的原文件不会复制或持续关联，导入后只保存转换后的台本。
- 扫描版/图片式 Word 文档、OCR、`.docm`、`.dot`、`.dotx`、`.odt`、`.rtf`、PDF 和 Markdown 导入均未实现。
