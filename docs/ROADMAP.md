# 开发路线图

路线图描述可能的后续阶段，不承诺具体发布日期。

## 阶段一：稳定本地工作流

- 完善真实台本库和编辑器的边界状态、恢复和错误提示。
- 补充 Android 设备、横竖屏、字体缩放和输入法矩阵测试。
- 完善无障碍语义、TalkBack 和大字体布局。

## 阶段二：文件导入

- 支持 TXT、DOCX、Markdown 和系统文件选择器。
- 将导入内容转换为 `ScriptDocument`，由 Repository 统一派生纯文本、字数和预计时长。
- 增加导入失败、编码识别和超大文档处理。

## 阶段三：播放稳定性

- 进行长时间播放、掉帧、Activity 重建和方向切换压力测试。
- 完善播放 Session 快照、恢复策略和更多设备 Insets 组合。
- 增加截图/布局回归和现场使用诊断信息。

## 阶段四：局域网控制端

- 实现一对一设备发现、二维码配对和安全连接。
- 同步台本、准备状态、播放位置、速度和暂停/恢复事件。
- 在现有 UI 状态和事件接口基础上替换本地 Mock Session。

## 阶段五：多设备与语音研究

- 评估一对多控制和多台提词端扩展。
- 研究逐词位置、语音跟随和语速自适应。
- 根据稳定性和隐私要求评估是否需要可选云同步。

## 发布准备

- 建立真实 CI 构建和测试检查。
- 完善隐私说明、正式截图、测试版本说明和崩溃反馈流程。
- 在功能和设备矩阵达到可接受稳定性后，再准备首个测试版本。
